# renpy-overlay

## 一、这是什么

**renpy-overlay** 是一个 Windows 桌面工具：把正在运行的 Ren'Py 游戏里出现的**每一句对话**，实时"搬"到一个漂浮在游戏画面上的透明小窗口里，并且可以**一键翻译成中文**。

它解决的问题是：玩外语 Ren'Py 游戏时，游戏内文字看不懂、切词典麻烦。装上本工具后——

- 游戏推进到哪句，悬浮窗就显示哪句（不堆积旧内容，始终是最新一句）；
- 想看中文？锁定悬浮窗后单击一下，译文像打字机一样逐字流出来；
- 懒得点？开启自动翻译，每句对话自动翻；
- 还附带一整套游戏伴侣功能：截图翻译、AI 对话、听歌识曲、语音识别、视频录制与剪辑、各类历史记录。

> 不支持网页版与安卓版 Ren'Py；仅支持 Windows 10 / 11。

**给开发者的技术文档**（实现原理、架构、协议、源码结构）全部在 [doc/](doc/README.md)，本文只讲怎么用。

## 二、软件亮点

| 亮点 | 你能感受到什么 |
| --- | --- |
| 实时对话悬浮窗 | 全透明、始终置顶、可拖动；只显示文字不遮挡画面；随游戏窗口移动，游戏最小化自动隐藏 |
| 打字机流式翻译 | 锁定后单击即翻，译文逐字流出；大段文字不滚出视野，滚轮可回看全文 |
| 自动翻译 + 缓存 | 锁定后自动翻译最新对话；翻过的句子再遇到时瞬间上屏，不重复请求 |
| 分支选项捕获 | 剧情选项出现时正文显示编号选项列表，选择后提示你选了哪项；标题窗图标可打开「选项副作用日志」弹窗，查看各选项的好感度/flag 变化语句（事前预测灰字、选择后翻转为已发生淡蓝） |
| 截图翻译 | 在画面上框一块区域，单击即把区域内文字识别并翻译（最多 8 块区域，彩色边框区分） |
| 快捷键模式 + 遥控截图 | 全局热键触发截图翻译；粉色小圆"遥控器"瞄准区域一键截屏，可自动周期截图 |
| 锁鼠标区域 | 把鼠标限制在框选范围内，防止误点出游戏窗口 |
| AI 对话 | 向 AI 提问学外语：可 OCR 截图区域的原文再发问；支持查看历史 |
| 听歌识曲 | 一键录制系统声音识别"这是哪首歌"（Shazam），历史可标注场景备注 |
| 语音识别 | 实时把游戏语音转文字上屏；剪辑里还能给视频批量做双语字幕 |
| 视频录制与剪辑 | 一键录制全屏+系统声音；内置剪辑器（分割/合并/波形/字幕/导出） |
| 完整历史记录 | 翻译、截图、对话、识曲、语音识别五类记录全部可回看、搜索、编辑、删除 |
| 跳过注入模式 | 非 Ren'Py 游戏也能用截图翻译、识曲、AI 对话等功能 |

## 三、环境搭建

### 3.1 你需要准备

| 条件 | 说明 |
| --- | --- |
| Windows 10 / 11 | 仅桌面版 |
| [uv](https://docs.astral.sh/uv/) | 包管理器，官网下载安装后命令行可用 `uv` 即可 |
| 目标游戏 | Ren'Py 7.x（32 位）或 8.x（64 位）的**桌面版**，且已经启动到游戏主循环 |
| 同一用户运行 | 工具和游戏用同一个 Windows 账户启动；游戏若以管理员启动，本工具也要管理员 |
| （推荐）Rust 工具链 | 影响听歌识曲功能的依赖安装。从 https://rustup.rs 安装；不装也行——只要依赖能下载到预编译包，其余功能不受影响 |

### 3.2 安装（一条命令）

```bash
uv sync
```

会自动创建虚拟环境并装好全部依赖。默认走清华镜像下载（写在 `pyproject.toml` 里）；想换源可改该文件或设置环境变量 `UV_DEFAULT_INDEX`。

### 3.3 不想装 Python 环境？（可选）

可用 PyInstaller 打包成免安装的 exe：

```bash
uv run pyinstaller renpy_overlay.spec --noconfirm
```

产物为 `dist/renpy-overlay/` 目录，**整个文件夹一起拷走**，运行其中的 `renpy-overlay.exe` 即可（无需 Python）。首次运行会在 exe 旁边自动生成 `config.json`。打包细节见 [doc/build-and-packaging.md](doc/build-and-packaging.md)。

## 四、快速上手（3 步跑起来）

```bash
# 第 1 步：先启动你的 Ren'Py 游戏，进入有对话的画面

# 第 2 步：列出候选进程，确认能看到游戏
uv run renpy-overlay --list

# 第 3 步：注入（弹出选择窗，双击你的游戏进程或点"注入"）
uv run renpy-overlay
```

也可以直接指定进程号：`uv run renpy-overlay --pid 12345`。

注入成功后：

1. 游戏画面上方出现**透明悬浮窗**（上面一条标题、下面一块正文），游戏每推进一句对话，正文实时刷新；
2. **按住标题或正文拖动**可整体挪位置；**双击**锁定/解锁位置；
3. **锁定状态下单击** → 把当前对话原文翻译成中文（需要先完成下面的"翻译配置"）；
4. 默认已开启**自动翻译**：锁定后自动逐句翻译，无需手动点。

### 翻译配置（重要，一次即可）

翻译默认连接本机 [LM Studio](https://lmstudio.ai/)：

1. 安装并打开 LM Studio，加载任意一个能翻译的模型，开启本地服务（默认端口 1234）；
2. 完成。本工具默认连 `http://127.0.0.1:1234`，模型代号留空时会自动选用已加载的第一个模型。

也可以改用 OpenAI / DeepSeek 等在线平台：编辑项目根目录的 `config.json`（首次运行自动生成），把 `api_base_url` / `api_key` / `model` 改成对应平台的地址与密钥即可。所有可配置项见下方 5.5 小节与 [doc/config.md](doc/config.md)。

不想用翻译？其余功能（截图翻译、识曲、AI 对话等同样需要 API；录视频、锁鼠标、历史记录不需要）。

## 五、使用说明

### 5.1 悬浮窗鼠标操作

| 操作 | 效果 |
| --- | --- |
| 按住标题/正文 + 左键拖动 | 两窗整体移动；松手后位置固定，不再被自动停靠拉回 |
| 左键双击 | 锁定/解锁位置（锁定后不响应拖动；双击同时中止在途翻译与识曲） |
| 锁定状态下单击 | 翻译最近一句游戏原文，译文逐字流入（未锁定不触发） |
| 锁定状态下按住正文文字上下滑动 | 滚动回看文本：小幅移动不滚动，大幅移动快速滚动 |
| 鼠标滚轮（悬浮窗内） | 回看当前对话全文；滚回顶部恢复"固定首行"显示 |

实时语音识别开启期间，滚轮改为"跟随最新内容"：上翻回看暂停跟随、滚回底部恢复。

快捷菜单锚点（独立圆形悬浮钮，设置图标）：

| 操作 | 作用 |
| --- | --- |
| 锁定态左键单击 | 打开/关闭快捷菜单（见 5.3；菜单自动出现在锚点左侧或右侧空余一侧，不覆盖锚点） |
| 左键双击 | 切换锚点锁定/解锁（默认锁定） |
| 解锁态按住拖动 | 移动锚点位置 |

锚点位置、大小与锁定状态随退出写入 layout.json，下次启动自动恢复；直径可用 `quick_menu_anchor_diameter` 调整（默认 50）。

### 5.2 控制台命令

启动工具的终端窗口里可输入单字母命令：

| 命令 | 作用 |
| --- | --- |
| `h` | 隐藏/显示悬浮窗 |
| `d` | 恢复默认自动停靠（撤销手动拖动位置） |
| `u` | 卸载游戏内代理（恢复游戏原状，本工具随后可继续用 `--status` 查看） |
| `s` | 查看代理状态 |
| `q` | 退出工具 |

### 5.3 快捷菜单

| 菜单项 | 作用 |
| --- | --- |
| 创建截图窗口 / 销毁截图窗口 | 在屏幕上放置（最多 8 个）彩色边框选区；双击锁定后单击即翻译该区域文字 |
| 快捷键模式 | 隐藏所有窗口并注册全局热键：主开关 Alt+T + 数字 1-8 触发对应截图区翻译 |
| 锁鼠标区域 | 把鼠标限制在框选范围内（双击生效；Alt+O 为保底逃脱键） |
| 遥控器自动化 / 隐藏遥控器 | 配合遥控截图的自动周期截图翻译（需先开启快捷键模式出现遥控圆窗） |
| 录制视频 | 开关式全屏录制（含系统声音），存到游戏目录 `renpy_overlay_cache/video/` |
| 视频剪辑 | 打开内置剪辑器：分割/合并/标记切片/波形/时间轴/做双语字幕/导出 |
| 实时语音识别 | 把系统播放的声音实时转文字上屏（需单独配置实时识别 API） |
| 听歌识曲 | 录 8 秒系统声音识别歌曲，结果显示在正文窗 |
| 对话 | 打开 AI 对话窗口（可 OCR 截图区原文后向 AI 提问） |
| 预构建翻译缓存 | 离线批量预翻译游戏脚本，提前填好翻译缓存 |
| 查看历史 | 翻译历史 / 截图历史 / 识曲历史 / 对话历史 / 语音识别历史 五个浏览窗口 |
| 设置 | 打开双栏设置窗口（图形化改 config.json） |
| 退出 | 关闭工具并自动清理游戏内代理 |

### 5.4 常用命令行参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--pid PID` | — | 直接指定游戏进程，跳过选择窗 |
| `--list` | — | 只列出候选进程后退出（`--all` 连低分候选一起列） |
| `--no-gui` | — | 用命令行菜单代替图形选择窗 |
| `--unload` | — | 卸载目标游戏内的代理后退出 |
| `--status` | — | 查询游戏内代理状态后退出 |

| `--dock POS` | `top-center` | 悬浮窗停靠位置（六种，如 `bottom-center`） |
| `--port` | `0` | 内部通信端口（一般不用改，默认由系统分配） |
| `--poll-hz` | `7.0` | 游戏内兜底轮询频率（收不到对话时可调高） |

| `--log-level / --log-dir / --log-file` | `INFO / logs / 自动` | 日志配置 |

### 5.5 config.json 配置说明

配置文件在项目根目录（打包版在 exe 旁边），首次运行自动生成，可用记事本编辑，也可用快捷菜单「设置」图形化修改。**改完保存，设置窗口点「确定」即可热重载生效；确认后可按弹窗提示一键重启，统一载入全部新配置**。完整键表（含默认值、取值范围、非法值回退规则）见 [doc/config.md](doc/config.md)，下面是最常用的键：

```jsonc
{
  "auto_translate": true,            // 自动翻译开关（仅锁定状态生效）
  "auto_translate_interval": 1.0,    // 自动翻译轮询间隔（秒）
  "show_original_text": false,       // 正文是否随对话显示游戏原文
  "api_base_url": "http://127.0.0.1:1234",  // 翻译 API 地址（LM Studio / OpenAI / DeepSeek 等兼容平台）
  "api_key": "",                     // API 密钥；本地服务通常留空
  "model": "",                       // 模型代号；留空自动选已加载的第一个
  "api_base_url_vision": "",         // 截图翻译用视觉 API；留空跟随主 API
  "model_vision": "",                // 视觉模型；留空自动选（需支持看图）
  "api_base_url_asr": "",            // 语音识别 API；留空跟随主 API
  "model_asr": "",                   // 语音识别模型；留空跟随主模型（需支持音频）
  "api_base_url_asr_rt": "",         // 实时语音识别 API（三项都必填才可用，不回退其它项）
  "model_asr_rt": "",
  "api_key_asr_rt": "",
  "enable_thinking": false,          // 模型"思考"模式开关，建议关闭（更快）
  "stream_window_width": 1760,       // 正文窗宽度（会被游戏窗口宽度限制）
  "stream_window_height": 200,       // 正文窗高度
  "stream_window_font_size": 16,     // 正文字号
  "translate_window_style": 1,       // 1=淡蓝打字机样式；2=半透明黑底整段样式
  "body_fill_color": "#ADD8E6",      // 样式 1 的标题/正文文字颜色（十六进制，点设置窗口「确定」后即时生效）
  "screenshot_compress_percent": 10, // 截图发送前压缩比例（省流量）
  "recording_duration": 8,           // 听歌识曲录音秒数
  "hotkey_main": "alt+t",            // 快捷键模式主开关键
  "remote_screenshot_enable": true,  // 遥控截图小圆窗开关
  "remote_cache_persist_enable": false, // 遥控器自动化持久化缓存（默认关）
  "remote_cache_db_size_count": 40000, // 持久化缓存条数上限（冷端随机淘汰）
  "remote_settle_frames": 3         // 稳定窗口帧数（打字机过滤）
}
```

几个使用要点：

- **翻译 API 分三条独立链路**：文字翻译（主链路）、截图翻译（vision 三键）、语音识别（asr / asr_rt 各三键）。留空的键自动"跟随"主链路；唯独实时识别（asr_rt）三项**必须全部填写**才可用；
- `enable_thinking: false` 时工具会按各平台的方言自动声明关闭思考（LM Studio 需要额外的 `reasoning_effort: "none"`，工具已代劳）；关闭后单句翻译约半秒，开启思考可能要 30 秒以上；
- **遥控器自动化持久化缓存（可选，默认关）**：`remote_cache_persist_enable` 开启后，自动化截图翻译命中顺序为「内存 → 数据库 → API」，同一画面跨会话直接复用译文（命中直接上屏、不发 API 也不入历史）；缓存译文不对时再次单击触发器 A 即强制重新翻译；手动单击截图窗与快捷键截图翻译始终走 API 不查缓存，不受影响；
- **打字机过滤**：`remote_settle_frames`（默认 3）让自动化等画面连续稳定后再翻译，避免逐字输出期间反复翻译半句；
- 配置写错（类型不对、数值越界）不会导致程序崩溃：该项自动回退默认值并记入日志。

### 5.6 预构建翻译缓存

想让自动翻译"秒出"？可以在玩游戏前**离线批量预翻译**整个游戏的脚本：

1. 注入成功后，点标题窗右侧的「预构建翻译缓存」图标（或快捷菜单同名项）；
2. 「.rpy 翻译缓存」页签：扫描游戏脚本 → 勾选要处理的文件（支持分批）→ 开始处理，工具自动逐条翻译并写入缓存；
3. 另两个页签可把 `.rpyc` 反编译、把 `.rpa` 解包（依赖随包附带的两个开源小工具，见 [doc/pretranslate.md](doc/pretranslate.md)），解出来的脚本同样可被扫描翻译；
4. 游戏内再遇到这些句子时直接命中缓存，瞬间上屏。

可随时取消，已翻好的条目保留；下次进入自动跳过已入库条目。相关并发参数见 [doc/config.md](doc/config.md)。

### 5.7 数据保存在哪里

所有记录都写在**游戏目录**下的 `renpy_overlay_cache/` 文件夹里（跳过注入模式下是你指定的目录）：

| 文件/目录 | 内容 |
| --- | --- |
| `translations.db` | 翻译缓存（预构建与运行时共用） |
| `screenshot.db`（+ `screenshot/` 导出目录） | 截图记录（原图、缩略图、译文） |
| `chat.db` | AI 对话记录 |
| `game_song.db` | 识曲记录（游戏场景、备注可编辑） |
| `asr.db` | 语音识别记录（含音频片段） |
| `video/` | 录制的视频 |

删除数据库不影响工具运行；历史窗口里可浏览、搜索、编辑、删除单条记录。

### 5.8 常见问题与排障

| 现象 | 怎么办 |
| --- | --- |
| `--list` 里看不到游戏 | 加 `--all` 看全部进程；确认游戏已进入主循环（不是启动器）；游戏是管理员启动时，本工具也要管理员运行 |
| 注入报权限错误（error=5） | 以管理员身份运行本工具；确认工具与游戏是同一 Windows 账户 |
| 注入报"未找到 Python 运行库" | 打包版/自编译游戏可能不带 Python 运行库，暂不支持；可把完整模块清单（日志 DEBUG 里）发给我们确认 |
| 注入被拦截或失败 | 杀毒软件/EDR 可能拦截远程注入，见下文"合规与安全"；可将本工具目录加入白名单（仅限自己的电脑） |
| 注入成功但收不到对话 | 游戏停在主菜单时没有对话属正常；看日志里"游戏端确认 Hook 层" |
| 悬浮窗被游戏画面盖住 | 游戏处于独占全屏时其它窗口无法置顶，请改用**窗口化 / 无边框窗口化**运行游戏 |
| 退出后游戏里有残留 | 运行 `--unload`；正常退出工具会自动清理 |
| 翻译一直失败 | 确认 LM Studio 已启动并加载模型、本地服务已开启；用在线平台则检查 `api_base_url`/`api_key`/网络 |
| 含 Ctrl 的快捷键让游戏一直快进 | 这是 Ren'Py 自身行为（Ctrl 是快进键），换用不含 Ctrl 的键（如 `alt+f9`）；工具在开启快捷键模式时也会提示 |
| 听歌识曲总失败 | 关闭游戏音效再试；多次失败通常是该曲目未被 Shazam 收录；蓝牙耳机可能不支持声音环回 |
| 视频功能提示不可用 | 视频组件（PyAV）需要较新 Python（≥3.12）；升级后重装依赖 |

日志位置：`logs/renpy_overlay_<时间戳>.log`（DEBUG 全量细节都在里面，提问时请附上它）。

### 5.9 已知限制

- 仅支持 Windows 桌面版 Ren'Py（7.x / 8.x）；不支持网页版、Android；
- 游戏刚启动、Ren'Py 尚未初始化完成时注入会失败，稍等片刻重试即可；
- 把 Python 静态打包进主程序的自定义游戏构建无法注入；
- 独占全屏模式下悬浮窗无法置顶（请窗口化运行）。

## 七、合规与安全

本工具使用"远程线程注入"（Windows 的 `OpenProcess` + `CreateRemoteThread` 等接口），这是杀毒软件眼中的典型可疑行为特征：

- 请仅用于**你自己的游戏、自研项目或已获得授权**的本机调试与学习；
- 请勿用于绕过游戏保护、破解、作弊或任何违反游戏服务条款与当地法律的用途；
- 工具与游戏的所有通信只走本机回环地址（127.0.0.1）并带随机令牌握手，不对局域网/公网开放任何端口。
